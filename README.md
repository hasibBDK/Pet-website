Project Name

Peddy – Pet Adoption Platform

Short Description

Peddy is a responsive pet adoption web application where users can browse pets by category, view detailed information, like their favorite pets, and explore available pets in a clean and user-friendly interface. The project uses real-time data from an API and is built with modern JavaScript (ES6), Tailwind CSS, and DaisyUI.


5 Key Features of the Project

Category-based Pet Filtering
Users can filter pets by category (Dog, Cat, Bird, etc.) using dynamic buttons fetched from an API.

Dynamic Pet Listing
All pet cards are generated dynamically using JavaScript and displayed in a responsive grid layout.

Like / Favorite Pets Feature
Users can like pets, and the selected pet images appear instantly in a separate “Liked Pets” section.

Pet Details Modal
Clicking the “Details” button opens a modal showing complete information about the selected pet.

Responsive Design
The application is fully responsive for mobile, tablet, and desktop devices using Tailwind CSS utilities.

ES6 Features Used

Arrow Functions
Template Literals
Array Methods (forEach)
Fetch API with Promises
